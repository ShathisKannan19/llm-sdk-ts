# Support

## Getting Help

- Read [README.md](README.md) for usage and examples.
- Search existing issues before creating a new one.

## Where to Ask

- Usage questions: open a GitHub issue with repro details.
- Bugs: use the bug report template.
- Security: follow [SECURITY.md](SECURITY.md).

## What to Include

- Node version
- package version
- provider used
- minimal reproducible code
- expected vs actual behavior
