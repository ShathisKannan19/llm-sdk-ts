# Security Policy

## Supported Versions

Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately.

- Preferred: GitHub Security Advisories for this repository.
- Alternative: contact maintainers directly.

Include:
- affected version
- reproduction steps
- impact assessment
- suggested mitigation (if known)

Do not disclose vulnerabilities publicly until maintainers confirm and patch.

## Disclosure Process

1. Acknowledge report.
2. Validate and triage severity.
3. Prepare and test fix.
4. Publish patched release and advisory.
